音のルール

みんなが苦手な音のルール、
この4つ。

どれも飲食店でよく聞こえる音です。実際の音声で、1つずつ聞き取れるか確認しながら、スラスラ言えるようにしていきます。

  1. Flap T

    母音に挟まれた t が、「ら行」の音に変わります。

    "be about a" → 「びぁばぅら」

  2. 消えるT

    語末の t は破裂させず、舌を止めるだけで終わります。

    "wait" → 「うぇい」で止まる

  3. 母音ドッキング

    母音で始まる単語が、前の単語とくっつきます。

    "Can I" → 「けなぃ」

  4. 機能語の弱形

    can・to・It’ll などが、弱く短くつぶれます。

    "can" → 「けん」「くん」

この4つは、次の3つの音声にすべて入っています。

01カフェのレジで

For here or to go?

店内で召し上がりますか？ お持ち帰りですか？

単語と言い方

  • for here ＝ 店内で（飲む・食べる）。
  • to go ＝ 持ち帰りで。北米では「テイクアウト」より to go が普通の言い方です。

文の形

「A or B?」の二択なので、Yes / No ではなく、どちらかを答えます。北米のカフェでよく聞かれる質問です。

発音Tips

  • おぅの二重母音"go" の o は、「ごー」ではなく「ごぅ」のように、二重母音として発音します。

※発音解説は北米英語の発音を基準にしています

つながる音Tips

  • 前置詞"For" は "f" の音だけのように軽く発音され、次の "here" にドッキングします。
  • 母音ドッキング"here or" はつながって「ひあor」のように一息で聞こえます。
  • Toの弱形"to go" の to は「とぅー」と伸びず弱く短くなり、必ず次の単語（go）にドッキングします。to は「t'＋次の単語」（ここでは t'go）のように常に発音されます。to の t は軽く弾いて「る」に近く聞こえることもあります。

こう返せます

  • For here, please.（店内で）
  • To go, please.（持ち帰りで）
02入り口で、席を待つとき
英文と聞こえ方を見る+

It’ll be about a 20-minute wait.

20分ほどお待ちいただくことになります。

単語と言い方

  • It’ll ＝ It will の短縮形。
  • wait ＝ ここでは「待ち時間」（名詞）。about ＝ 約・およそ。

文の形

質問ではなく案内です。返事は "That’s okay."（それなら待ちます）で十分。いちばん大事なのは数字（20）の聞き取りです。

発音Tips

  • 機能語の弱形"It’ll" の t は「ろ」のような音に変身し、「ぇろぅ」のように短くつぶれて聞こえます。「イット ウィル」とは聞こえません。will は、基本的に「うぃる」とは発音されず、「ぅ」のようなリズム感、音で発音されます。
  • い/えの中間音"minute" の i は、日本語の「い」ではなく、「え」と「い」の中間のような音です。

※発音解説は北米英語の発音を基準にしています

つながる音Tips

  • Flap T"be about a" の t は母音に挟まれて「ら行」の音に変身し、「びぁばぅら」のように聞こえます。
  • 消えるT"minute" の最後の t は強く発音されず、「みにっ」のように止まって聞こえます。
  • 消えるT文末の "wait" の最後の t も同じく破裂させず、舌をtの位置で止めるだけで終わります。

こう返せます

  • That’s okay.（それなら待ちます）
  • We’ll wait.（待ちます）
03レストランで、席に着いたら
英文と聞こえ方を見る+

Can I start you off with something to drink?

まず、お飲み物はいかがですか？

単語と言い方

  • start you off with ○○ ＝ まず○○から始める。「まずお飲み物からいかがですか」という、お店の決まった言い方です。直訳の「あなたをスタートさせる」で考えると、意味が取れません。

文の形

文は長いですが、聞かれていることは "Something to drink?" と同じです。全部聞き取れなくても、drink さえ拾えれば答えられます。長い文は、拾う単語を1つ決めておくのがコツです。

発音Tips

  • 機能語の弱形"can" は文中では弱く「けん」や「くん」のように短く聞こえます。
  • い/えの中間音"with"（うぇth）、"something"（smthぇん）、"drink"（Drぇんk） の i は、日本語の「い」ではなく、「え」と「い」の中間のような音です。この3語とも、カナでは「ぇ」と書いています。
  • ngの止め方"something" の最後の ng は、g を発音せず、鼻から息を抜く「ん」に近い音で止めます。

※発音解説は北米英語の発音を基準にしています

つながる音Tips

  • 母音ドッキング"Can I" はつながって「けなぃ」のように一息で聞こえます。同じことが "you off" でも起きて、off の o が直前の you にくっつき、「ちゅあf」のようにひと続きに聞こえます。
  • Toの弱形"something to drink" の to は「とぅー」と伸びず弱く短くなり、必ず次の単語（drink）にドッキングします。to は「t'＋次の単語」（ここでは t'drink）のように常に発音されます。to の t は軽く弾いて「る」に近く聞こえることもあります。

こう返せます

  • Just water, please.（お水だけで）
  • I’ll have a Coke.（コーラにします）

なぜ聞こえないのか

知らない単語は、
ありましたか？

3つとも、中学校で習う単語だけでできています。知らない単語は、たぶん1つもなかったはずです。

それでも聞き取れないのは、英語が単語ごとに区切って発音されないからです。となりの単語とくっつき、弱くなり、別の音に変わります。文字で覚えた形と、耳に届く音が、まったく別物になる。これが、何年勉強しても店先で固まってしまう理由です。

このルールは、知らないあいだは何回聞いても聞こえません。知った瞬間に、聞こえるようになります。レッスンは、その「知った瞬間」に出会う機会です。
