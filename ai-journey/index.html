Automation

手でやっていた作業を、自動で動く仕組みに

毎回人がやっていた入力や連絡を、道具どうしをつないで自動にしています。今、実際に動いているものです。

支払いからお礼のメールまでの流れは、10分かからずに組んで動かしました

  • 動画や写真ができたらClaude Code から Instagram・Threads・YouTube へ投稿を予約するBuffer・Cloudflare R2
  • 支払いが済んだら申込者の一覧に入り、お礼のメールが届くStripe・Zapier・MailerLite
  • 購入した人に使い方の案内メールが自動で届くMailerLite
  • 毎週月曜の朝にその週の発信の準備を知らせるメールが届くZapier
  • サイトを直すたびに文字の大きさ・押しやすさ・携帯での見え方を自動で測るPlaywright

AI talk

店員役の、声で話すAIエージェント

場面ごとに役と決まりを持たせたAIエージェントが店員になり、こちらの英語に声で答えます。話がそれないように指示を組み、一回の購入で使える回数も数えています。同じ仕組みは、電話や受付、お客様対応のAIエージェントにも応用できます。

For you

I don’t just use AI. I build with it.

AIに聞いて終わりではなく、AIと一緒に、動くものを作ります。AIを使うので、作るのが速く、直すのもすぐです。たとえば、こんなことをやってくれるんです。

  • 予約・支払いの自動化

    申し込み、支払い、確認のメール、顧客の一覧への登録までをつなげて、手で打ち込む作業をなくせる！

  • SNSへの投稿の自動化

    動画・カルーセル・写真を、Instagram・Threads・YouTube へまとめて予約投稿できる仕組みが作れるし、メールの配信や毎週の知らせも自動にできる。

  • 問い合わせに答えるAIエージェント

    よくある質問に答えるAIや、声で受け答えするAIを、会社の決まりに合わせて作るのだって簡単！

  • 社内のくり返し作業

    フォームの内容を表にまとめる、毎週の報告を送るなど、毎回手でやっていることをあっという間に自動化できます。

  • ウェブサイト

    日本語・英語・フランス語で作ります。他の言語だって作れちゃう。携帯で開いた最初の一画面まで測り、公開後の直しもすぐに対応できるところがスゴイ！

  • 短い動画・AIの音声

    動画素材と言いたい言葉から、字幕（英語・フランス語）とナレーションをそろえます。好みの声を選んで、AIで音声も作れます。写真からリップシンクで話させる動画を作ることもできます。
